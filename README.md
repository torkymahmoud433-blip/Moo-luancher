# Android Web Emulator (Android 12)

مشروع تجريبي لتجهيز واجهة محاكي أندرويد يعمل من المتصفح.

## الحالة الحالية
- واجهة ويب أولية.
- لم يتم دمج QEMU-Wasm بعد.
- لا يمكن حاليًا إقلاع Android 12 أو تشغيل ملفات ROM من هذه النسخة.

## خطة التطوير
1. تجهيز واجهة تشغيل وإعدادات المحاكي.
2. تحديد صورة النظام ومعماريتها.
3. دمج محرك افتراضي WebAssembly مناسب.
4. إعداد ملفات الإقلاع والتخزين المتوافقة.
5. اختبار الإقلاع داخل المتصفحات المدعومة.

## توافق مهم
معظم رومات الهواتف مبنية لمعمارية ARM64، بينما كثير من تجارب QEMU-Wasm تستخدم x86_64. اختيار صورة النظام وحده لا يكفي؛ يجب توافق المعمارية والـ boot chain والـ kernel وملفات التخزين.

## التشغيل
افتح `index.html` عبر GitHub Pages أو خادم محلي. اختيار ملف النظام في الواجهة حاليًا للعرض فقط ولا يمرره إلى محرك افتراضي.
